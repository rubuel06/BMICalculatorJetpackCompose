Calculadora IMC - Jetpack Compose 📱Projecte d'una calculadora d'Índex de Massa Corporal (IMC) per a Android desenvolupada amb Jetpack Compose. El projecte s'ha fet per aprendre a treballar amb Compose, gestionar l'estat de l'aplicació i provar de personalitzar la interfície per sortir del disseny per defecte.📸 Dissenys de la UIAquí es pot veure la diferència entre la versió inicial senzilla i el redisseny d'estil Synthwave / Neó:UI Bàsica (Material 3)UI Synthwave(Enganxa imatge 1)(Enganxa imatge 2)Nota: Perquè es vegin les imatges, pots pujar les captures a la carpeta del projecte i posar la seva ruta aquí com ![Material3](captura1.png).🌿 Branques de GitEl repositori té dues branques per poder comparar el procés de desenvolupament:master: Té la versió inicial de la calculadora amb el disseny estàndard de Material Design.UI-bonica: Branca on s'ha aplicat tot el redisseny visual estil Synthwave (colors neó, fons amb gradients, tipografia retro i formes personalitzades).🛠️ Tecnologies utilitzadesLlenguatge: KotlinUI Framework: Jetpack Compose (Material 3, @composable, Gradients i Custom Shapes)IDE & eines: Android Studio, Git i GitHub
