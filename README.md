# Calculadora IMC - Jetpack Compose 📱

Projecte d'una calculadora d'Índex de Massa Corporal (IMC) desenvolupada per a Android utilitzant **Jetpack Compose**. L'objectiu principal ha estat aprendre la gestió de l'estat en Compose i experimentar amb el redisseny d'interfícies.

## 🌿 Branques de Git

El repositori està organitzat en dues branques per veure el procés de desenvolupament:

- **`master`**: Conté la versió inicial de la calculadora amb la interfície estàndard de Material 3.
- **`UI-bonica`**: Branca on s'ha aplicat el redisseny visual estil Synthwave / Neó (colors cridaners, fons amb gradients, tipografia retro i formes personalitzades).

---

## 🛠️ Tecnologies utilitzades

- **Llenguatge:** Kotlin
- **UI Framework:** Jetpack Compose (Material 3, `@Composable`, Gradients, Custom Shapes)
- **IDE & Eines:** Android Studio, Git i GitHub
